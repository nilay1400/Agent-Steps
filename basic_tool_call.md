## Step 1 — Tune WSL2 (Windows side)

System Python 3.14 was too new, and WSL had grabbed all 8 logical cores. Fixed via `.wslconfig` before touching Python.

**On Windows PowerShell:**

```powershell
notepad $env:USERPROFILE\.wslconfig
```

Wrote:

```ini
[wsl2]
memory=3.5GB
processors=4
swap=4GB
```

Then:

```powershell
wsl --shutdown
```

Reopened Ubuntu and verified:

```bash
free -h     # ~3.5 GiB Mem, ~4 GiB Swap
nproc       # 4
```

Left system Python 3.14 alone — `uv` will pin 3.12 per-project instead.

## Step 7 — First run (and the issues that followed)

Ran:

```bash
uv run python -m basic_agent.main
```

Four issues surfaced in sequence. All resolved — documented here so future-me doesn't re-debug them.

### Issue 1 — `LangGraphDeprecatedSinceV10: create_react_agent has been moved`

`create_react_agent` is deprecated in LangGraph v1.0; the new import is `from langchain.agents import create_agent`. Warning was cosmetic; switched to the new import (see Issue 4 before this actually worked).

### Issue 2 — Process hung with no output after `[ai]`

Cause: `ChatOpenAI` was created without `timeout` and with default retries. LangChain silently backed off on network failures instead of raising — the process looked frozen forever.

Fix: construct `ChatOpenAI` with `timeout=20, max_retries=0`. Hangs become 20-second errors.

### Issue 3 — `openai.APITimeoutError` / `ConnectTimeout: _ssl.c:993` on TLS handshake

Reproduced from WSL:

```bash
curl -4 -sS -o /dev/null -w "IPv4: %{http_code} %{time_total}s\n" \
  --max-time 10 https://api.groq.com/openai/v1/models
```

IPv4 worked; WSL2 was preferring IPv6 with a broken route. Fix: force IPv4 at the top of `main.py` before any `openai` import:

```python
import socket
_orig = socket.getaddrinfo
socket.getaddrinfo = lambda *a, **kw: [r for r in _orig(*a, **kw) if r[0] == socket.AF_INET]
```

(Alternative system-wide fix, not used: set `/etc/gai.conf` precedence.)

### Issue 4 — `ModuleNotFoundError: No module named 'langchain'` then `ImportError: cannot import name 'create_agent'`

Diagnostic that revealed the root cause:

```bash
uv pip list | grep -E "^(langchain|langgraph)"
# langchain-core   1.7.4
# langchain-openai 1.7.3
# langgraph        1.2.19
# → 'langchain' itself is MISSING
```

`create_agent` lives in `langchain.agents`, which is part of the **`langchain` meta-package**, not `langchain-core` / `langchain-openai` / `langgraph`. Fix:

```bash
uv add langchain
uv run python -c "from langchain.agents import create_agent; print('OK')"
```

That resolved both the ImportError and the deprecation warning in one go.

### Issue 5 — (Minor, self-inflicted) `grep: src/basic_agent/main.py: No such file`

Was running the command from inside `src/basic_agent/`, so the relative path doubled up. Lesson: run relative-path commands from the project root (`~/agents-course/basic-agent/`).

## How to run it (from now on)

From `~/agents-course/basic-agent/`:

```bash
uv run python -m basic_agent.main
```

- `uv run` reuses the project venv — no `source .venv/bin/activate` needed.
- First run after a dependency change rebuilds the venv (~30 s); subsequent runs are ~2 s.
- `.env` is auto-discovered by walking up from `main.py` — no shell exports needed.

### Acceptance smoke test

```bash
uv run python -c "
from basic_agent.main import agent
cases = [
    ('What is 47832 + 91347? Use the add tool.',         ['add']),
    ('What is the weather in Paris?',                    ['get_weather']),
    ('Use add for 47+30, and also the weather in Paris.', ['add','get_weather']),
    ('Tell me a joke.',                                  []),
]
for q, expect in cases:
    r = agent.invoke({'messages':[('user',q)]}, config={'recursion_limit':10})
    called = [tc['name'] for m in r['messages'] for tc in (getattr(m,'tool_calls',None) or [])]
    print(('PASS' if set(called)==set(expect) else 'FAIL'), '|', q[:45], '|', called)
"
```

All four should print `PASS`.

> **Note:** `12+30` will NOT call `add` — the model does trivial arithmetic in-head. Use big numbers or "Use the add tool" phrasing when testing routing.
